# Приоритетный план следующих шагов (Iteration 3)

После успешной реализации композиции по эскизу макета пользователя (Storage Hero слева на 2 строки + 2×2 сетка технических метрик справа + плитки приложений на всю ширину снизу), сформирован следующий план развития:

---

## Приоритет 1 (Высокий): Доработка сценариев хранилища и Shares
- [ ] **Интеграция сетевых папок (Shares Quick Peek):**
  - Добавить компактный переключатель или модальное окно на экран хранилища для просмотра основных папок (`appdata`, `Photos`, `domains`) без перегрузки главного экрана.
- [ ] **История температур и SMART:**
  - Добавить простой спарклайн динамики температуры дисков за последние 24 часа в шторку диска.
- [ ] **Настройка расписания Parity Check и Mover:**
  - В модальном окне операций массива добавить отображение времени следующего запланированного запуска задач.

---

## Приоритет 2 (Средний): Управление приложениями и Docker
- [ ] **Индикатор доступных обновлений:**
  - Интерактивное обновление контейнера прямо из шторки приложения (симуляция pull нового образа и перезапуска).
- [ ] **Группировка по Docker Compose:**
  - Визуальное объединение связанных контейнеров (например, стек базы данных и бэкенда) в единую группу.

---

## Приоритет 3 (UX-полировка и адаптивность):
- [ ] **Клавиатурные хоткеи:**
  - Навигация по дискам и карточкам с помощью стрелок (`ArrowUp`/`ArrowDown`), быстрое закрытие шторок по `Escape`.
- [ ] **Сравнение дисков:**
  - Режим параллельного сравнения параметров двух дисков при замене или миграции данных.

---

## Что намеренно пока НЕ входит в ближайший скоуп:
- Прямое подключение к GraphQL/REST API Unraid (будет исследовано только после полной финализации UX).
- Полномасштабный каталог Community Applications (содержит тысячи шаблонов, не нужен для тестирования Overview).
- Разрушительные дисковые операции и форматирование файловых систем.
