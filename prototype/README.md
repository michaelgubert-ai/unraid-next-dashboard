# Unraid Unified Overview Prototype (v0.3 — Iteration 3: Exact Layout Schematic)

Рабочий интерактивный прототип единого экрана управления сервером Unraid (**Overview**), объединяющий повседневные задачи экранов **Dashboard** и **Main**, с композицией по эскизу пользователя **«Above the Fold» (без вертикальной прокрутки на десктопе)**.

---

## 1. Быстрый запуск

Проект разработан на **React + TypeScript + Vite**. Не требует внешних баз данных, backend или Docker socket.

### Системные требования:
- Node.js >= 18
- npm >= 9

### Команды:

1. Перейти в папку прототипа:
   ```bash
   cd prototype
   ```

2. Установить зависимости:
   ```bash
   npm install
   ```

3. Запустить локальный сервер разработки:
   ```bash
   npm run dev
   ```
   Сервер запустится строго на локальном интерфейсе: `http://127.0.0.1:3000/`.

4. Собрать production-билд:
   ```bash
   npm run build
   ```

5. Автоматически переснять скриншоты во всех разрешениях:
   ```bash
   node capture_screenshots.js
   ```

## 2. Реализация композиции по схеме пользователя

Композиция экрана Overview выстроена строго по эскизу макета:

1. **Верхняя информационная панель (Hero + 2×2 Tech Grid):**
   - **Главный блок хранилища (слева, 1.15fr, высота на 2 строки):**
     - Свободное место как главный показатель: `5.65 TB Free` (массив) и `642 GB Free` (кэш).
     - Единый статус здоровья, шкалы заполнения Data Array и NVMe Cache.
     - Быстрый доступ к «Inspect Devices (4)» и меню управления массивом «Array Actions».
   - **Сетка 2×2 технических метрик (справа, 1fr × 1fr):**
     - Ряд 1: **CPU** (нагрузка 3%, температура 31°C, i5-12600K 4.8W, полоса нагрузки) и **RAM** (доступно 9.9 GB, использовано 6.1 GB из 16 GB DDR5, шкала 38%).
     - Ряд 2: **Network** (RX 24.5 Kbps / TX 108.6 Kbps, 1 Gbps Link, топ-процесс Plex Stream) и **GPU** (RTX 3060 2%, 59°C, VRAM 0.6 / 12 GB, NVENC Transcoder).

2. **Нижняя секция приложений и нагрузок (на всю ширину рабочей области):**
   - Сетка плиток приложений (Squircle Tiles): иконка, имя, компактный индикатор статуса, контекстное меню `···` (Web UI, Logs, Restart, Stop).
   - Интегрированная плитка виртуальных машин (ZimaOS-Test).
   - Никаких громоздких постоянных таблиц и дублирующих кнопок на первом уровне.

3. **Компактная верхняя панель (Header):**
   - Имя сервера, статус паритета, Uptime, кнопка «Array Actions», колокольчик уведомлений с выпадающим окном недавних событий и селектор демо-сценариев.

4. **Складываемый сайдбар:**
   - 58 px в сложенном состоянии (иконки с тултипами), разворачивается по клику до 210 px.

5. **Above the fold:**
   - На экранах 1440×900 и 1366×768 вся информация видна без вертикальной прокрутки.
   - На 1920×1080 макет эффективно масштабируется на всю доступную ширину без пустых полей.
   - На мобильных (390×844) карточки трансформируются в вертикальный стек с нижним меню навигации.

## 3. Демо-сценарии

В правом углу шапки доступен селектор 7 состояний:
- `Normal (Healthy)` — штатная спокойная работа;
- `Low Storage Warning` — массив заполнен на 92%, кэш на 94%;
- `Disk SMART Issue` — сбой накопителя Disk 1 (64 сектора, 49°C);
- `App Stopped Cleanly` — остановленный контейнер Plex (режим Standby, не ошибка);
- `Action Failed (Crash)` — падение Nextcloud (код 128);
- `Active Parity Check` — динамический прогресс проверки четности с таймером и кнопками паузы/отмены;
- `Connection Lost / Stale Data` — предупреждение о показе кэшированных данных.

Кнопка **«Reset» (↺)** в любой момент сбрасывает состояние к исходному.

---

## 4. Безопасность и изоляция

- Прототип работает исключительно в памяти браузера через `MockServerAdapter`.
- В кодовой базе отсутствуют любые внешние сетевые вызовы (`fetch`, `XMLHttpRequest`, `WebSocket`).
- Реальный сервер Unraid и его файловая система полностью изолированы от прототипа.
